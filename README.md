# Drivers-performance-and-fleet-operations-Dashboard-
The Drivers Performance and Fleet Operations Dashboard is a data analytics capstone project developed using Microsoft Power BI. The project focuses on analyzing fleet operations and driver performance.  The dashboard transforms logistics data into interactive visualizations and key performance indicators (KPIs) to support data-driven decision-making.
**Project Objectives**:
Monitor driver performance and trip completion.
Analyze fleet utilization and operational efficiency.
Evaluate fuel consumption and fuel efficiency.
Track trip distance, duration, and performance.
Monitor fleet maintenance costs and vehicle downtime.
Present key operational metrics through interactive dashboards.
Tools Used

Microsoft Power BI: Dashboard development, data visualization, and performance monitoring.

Microsoft Excel: Data preparation and dataset organization.

DAX: Creating measures and calculating key performance indicators.
